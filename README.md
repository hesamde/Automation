# Automation Discovery Tool · ابزار جلسه‌ی اتوماسیون

یک ابزار ساده برای جلسات مشاوره‌ی اتوماسیون. سؤال‌ها را از مشتری می‌پرسی و در پایان، تخمین صرفه‌جویی زمان و هزینه را نشان می‌دهد.

A simple tool for automation consulting meetings. Ask the client the questions, and at the end it estimates time and money saved.

---

## فایل‌ها / Files

- **`automation-fa.html`** — نسخه‌ی فارسی (راست‌چین)
- **`automation-de.html`** — نسخه‌ی آلمانی / Deutsche Version

## استفاده / Usage

فقط فایل را در مرورگر باز کن (دابل‌کلیک). نیازی به نصب یا سرور نیست.
Just open the file in any browser (double-click). No install or server needed.

## امکانات / Features

- ۶ مرحله سؤال کشف نیاز (شناخت بیزینس، فرایند، دردها، ابزارها، بودجه، موفقیت)
- محاسبه‌ی خودکار: صرفه‌جویی زمان (هفته/سال)، ارزش سالانه (€)، امتیاز آمادگی
- دو نما: **مشاور** (تحلیل کامل) و **مشتری** (فقط نتیجه)
- خروجی PDF تک‌صفحه‌ای برای مشتری
- کاملاً آفلاین — هیچ داده‌ای ارسال نمی‌شود، بدون هوش مصنوعی، فقط فرمول‌های JavaScript

## چطور حساب می‌کند / How it calculates

```
صرفه‌جویی زمان = ساعت هفتگی × بازده (قاعده‌مند ۸۰٪ | تا حدی ۵۵٪ | قضاوتی ۳۰٪) × ۵۲
ارزش سالانه   = ساعت سالانه × هزینه‌ی ساعتی + ۶۰٪ کاهش هزینه‌ی خطا
امتیاز آمادگی = میانگین ۴ عامل (تکرار، قاعده‌مندی، فرصت، شدت خطا)
```

اعداد تخمینی و برای گفت‌وگو با مشتری هستند.
